# Parkour Mod (Fabric, Minecraft 1.21.11)

Клиентский мод: паркур-режим с прыжками от стен, фиксацией на стене, лазанием на уступы,
бегом по стенам, разбегом и динамичной камерой.

## Сборка в IntelliJ IDEA
1. `File → Open` → выберите папку проекта → «Trust Project».
2. `File → Project Structure → SDK` = **JDK 21**; `Settings → Build Tools → Gradle → Gradle JVM` = **JDK 21+**.
3. Дождитесь Gradle sync (первый раз долго: качается и декомпилируется Minecraft).
4. Запуск для теста: Gradle → `Tasks → fabric → runClient` (или готовая конфигурация «Minecraft Client»).
5. Сборка jar: `Tasks → build → build`. Готовый мод: `build/libs/parkourmod-1.3.0.jar`
   (НЕ `-sources`). Положите в `mods/` рядом с Fabric API 0.141.6+1.21.11.

## Управление и назначение клавиш
Все клавиши: **Настройки → Управление → Parkour Mod**. У каждого действия своя клавиша.
Важное правило: **пока своя клавиша не назначена, действие работает на стандартной; как только назначили — только на своей.**

| Действие | Клавиша по умолчанию | Если назначить свою |
|---|---|---|
| Паркур-режим вкл/выкл | **G** | — |
| Разбег (4 с, плавно ×2) | **R** во время бега (спринта) | — |
| Рывок (прыжок на 3 / 5 / 7 блоков) | зажать **Прыжок + Шифт** на земле, отпустить — прыжок | зажать/отпустить свою клавишу (Прыжок+Шифт перестанет работать) |
| Скольжение (5 блоков) | **Шифт** на бегу (при зажатом Спринте или уже разогнавшись) | нажать свою клавишу на бегу |
| Фиксация на стене | в воздухе у стены зажать **Шифт** | зажать свою клавишу |
| Прыжок от стены (3–4 блока) | **Прыжок** при фиксации / беге по стене | нажать свою клавишу |
| Залезть на уступ | у края стены при фиксации **W** | нажать свою клавишу |
| Бег по стене | во время разбега прыгнуть на стену, держать **W** (высота зависит от взгляда) | — |

Пример: хотите рывок на **V** и скольжение на **C** — назначьте их в Управлении, стандартные сочетания для этих действий отключатся.
Если две ваши клавиши совпадают (например, рывок и скольжение на Шифт), скольжение имеет приоритет, когда вы бежите; когда стоите/идёте — заряжается рывок.

## Анимации (из Emotecraft-файлов)
Четыре ваших `.emotecraft` конвертированы в Java (`AnimClips.java`) и проигрываются на вашем персонаже
в паркур-режиме (видны от третьего лица, **F5**):
* **бег** — при спринте по земле, шаг ускоряется на разбеге;
* **бег по стене, левая/правая сторона** — в зависимости от того, с какой стороны стена (вход в позу, затем цикл);
* **прыжок от стены** — один раз при отскоке (и из фиксации, и из бега по стене).
Между анимациями плавный переход. Включается, ускоряется/замедляется и настраивается в Mod Menu → Анимация.
Если анимации левой и правой стены перепутаны местами — включите «Поменять анимации бега по левой/правой стене».
Ограничения: изгибы колен и локтей (bend) не поддерживаются — в ванильной модели их нет; анимации видите только вы.

Заменить/добавить анимацию: положите `.emotecraft` в `tools/emotes/`, поправьте `tools/build_animations.sh`
(формат `ИМЯ=файл:начало-конец` — тики зацикленного участка) и запустите его. Поддерживается бинарный формат
`.emotecraft` (версии 1 и 2) с любыми стандартными easing (кроме back/elastic/bounce).

Камера в паркур-режиме: тряска при беге, наклон при стрейфе, наклон при беге по стене
(в сторону, зависящую от стены), «удар» при приземлении, расширение FOV на разбеге.

## Настройка
Меню настроек: **Mod Menu → Parkour Mod → кнопка настроек** (нужны Mod Menu и Cloth Config API).
Там: длительность/перезарядка/множитель разбега, сила отскока, скорость сползания и бега по стене,
управление высотой на стене, тряска, наклоны, FOV. Если наклон на стене «не в ту сторону» —
включите «Инвертировать наклон». Настройки лежат в `config/parkourmod.properties` (можно править вручную).
Без Mod Menu/Cloth Config мод работает с настройками по умолчанию.

## Важно
* Поза «лёжа» при скольжении — клиентская: вы видите её у себя (F5), но другие игроки на сервере увидят вас стоящим. Из-за низкой хитбокс-позы проезд под потолком в 1 блок на сервере может «откатить» вас назад.
* Дальность рывка рассчитана для ровной поверхности; если во время прыжка держать W, улетите примерно на блок дальше.
* Мод клиентский: движение считает клиент. В одиночной игре и на серверах без строгого античита работает
  без проблем; строгие античиты могут ругаться на ускорение.
* Клавиши G/R по умолчанию свободны в ванили, но могут конфликтовать с другими модами — переназначьте.
